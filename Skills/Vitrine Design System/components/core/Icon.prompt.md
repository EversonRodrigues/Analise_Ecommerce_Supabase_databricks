Renders a Lucide icon (2px stroke) tinted with currentColor via CSS mask — use for every glyph in the UI.

```jsx
<Icon name="shopping-bag" size={22} />
<Icon name="heart" color="var(--danger-500)" label="Favoritar" />
```

Sizes: 16 (inline text), 20 (default, buttons), 24 (header). Names: https://lucide.dev/icons
