Pill button for all actions; use exactly one `primary` (lime) per view for the main commerce action (Adicionar ao carrinho, Finalizar compra).

```jsx
<Button variant="primary" size="lg" iconLeft="shopping-bag">Adicionar ao carrinho</Button>
<Button variant="secondary">Comprar agora</Button>
<Button variant="outline" size="sm">Ver detalhes</Button>
```

Variants: primary, secondary, outline, ghost, danger. Sizes sm 36 / md 44 / lg 52. Press shrinks to 98%.
